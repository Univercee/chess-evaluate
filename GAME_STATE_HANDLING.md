# Исправление обработки состояний игры

## Проблема

Ничья при повторении позиции (`isThreefoldRepetition()`) не срабатывала.

## Причина

При каждом ходе создавался новый объект `Chess` из FEN-позиции:

```typescript
const gameCopy = new Chess(game.fen());
```

Это приводило к потере истории ходов. Метод `isThreefoldRepetition()` в chess.js требует полную историю партии для определения повторений позиций, но при создании из FEN история была пустой.

## Решение

Сохраняем полную историю ходов при клонировании игры:

```typescript
const gameCopy = new Chess();
const history = game.history({ verbose: true });

// Воспроизводим все ходы для сохранения истории
for (const move of history) {
  gameCopy.move(move);
}
```

Теперь `gameCopy` содержит полную историю партии, и все методы определения состояний работают корректно.

## Обработка состояний игры

### Методы chess.js

1. **`game.isCheckmate()`** - мат
   - Возвращает `true`, если текущий игрок получил мат
   - Игра окончена, победитель - противник

2. **`game.isDraw()`** - любая ничья
   - Возвращает `true` для всех видов ничьей:
     - Пат (stalemate)
     - Троекратное повторение (threefold repetition)
     - Недостаток материала (insufficient material)
     - Правило 50 ходов (50-move rule)

3. **`game.isStalemate()`** - пат
   - Возвращает `true`, если нет доступных ходов, но король не под шахом

4. **`game.isThreefoldRepetition()`** - троекратное повторение
   - Возвращает `true`, если одна и та же позиция встречалась 3 раза
   - **Требует полную историю ходов!**

5. **`game.isInsufficientMaterial()`** - недостаток материала
   - Возвращает `true`, если недостаточно фигур для мата
   - Примеры: K vs K, K+B vs K, K+N vs K

6. **`game.isCheck()`** - шах
   - Возвращает `true`, если король текущего игрока под шахом

7. **`game.isGameOver()`** - игра окончена
   - Возвращает `true` для мата или любой ничьей
   - Эквивалентно: `isCheckmate() || isDraw()`

### Логика определения статуса

```typescript
if (game.isCheckmate()) {
  // Мат - игра окончена
} else if (game.isDraw()) {
  if (game.isStalemate()) {
    // Пат
  } else if (game.isThreefoldRepetition()) {
    // Троекратное повторение
  } else if (game.isInsufficientMaterial()) {
    // Недостаток материала
  } else {
    // Правило 50 ходов или другая ничья
  }
} else if (game.isCheck()) {
  // Шах - игра продолжается
} else {
  // Обычный ход - игра продолжается
}
```

## Важные замечания

### История ходов

- **Всегда сохраняйте историю ходов** при клонировании игры
- Используйте `game.history({ verbose: true })` для получения полной информации о ходах
- Без истории не работают: `isThreefoldRepetition()`, `isDraw()` (частично)

### Правило 50 ходов

- chess.js автоматически отслеживает правило 50 ходов
- Нет отдельного метода для проверки, но `isDraw()` возвращает `true`
- Правило: 50 ходов без взятий и движений пешек

### Троекратное повторение

- Позиция должна повториться 3 раза
- Учитывается: расположение фигур, очередь хода, права на рокировку, возможность взятия на проходе
- **Требует полную историю ходов**

## Тестирование

Для проверки работы всех состояний:

1. **Мат**: Играйте до мата
2. **Пат**: Создайте позицию пата
3. **Троекратное повторение**: Повторяйте одни и те же ходы
4. **Недостаток материала**: Уберите большинство фигур
5. **Правило 50 ходов**: Сделайте 50 ходов без взятий и движений пешек
